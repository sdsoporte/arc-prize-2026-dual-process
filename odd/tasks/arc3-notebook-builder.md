## 1. Why

The ARC-AGI-3 kernel notebook `notebooks/arc3_submission_kernel/submission.ipynb` **cannot be regenerated by any committed script**. Measured 2026-09-24:

```text
grep -rn "arc3_submission_kernel" --include=*.py --include=*.sh --include=Makefile .
  -> (no matches)

the notebook's own header claims, and does not hold:
  "Built from `agent/my_agent.py` via `scripts/build_notebook.py`"
  "re-run `make submit`"

  agent/my_agent.py            -> does not exist (source is src/arc3_spatial_memory_agent.py)
  scripts/build_notebook.py    -> does not exist (only data/arc-agi-3-kaggle-starter/scripts/)
  make submit / Makefile       -> does not exist
```

**This is the root cause of a live defect.** Because the notebook is assembled by hand, it
drifted from the source:

```text
notebook embedded agent : 304 lines, md5 0d6cfd4698
src/arc3_spatial_memory_agent.py : 338 lines, md5 3bcd6a59d1
IDENTICAL: False   (the diff is exactly the seed fix, ~25 lines)
```

The embedded copy still carries the pre-fix seeding
`int(time.time() * 1e6) + hash(game_id) % 1e6` — wall clock plus a per-process salted
`hash(str)`. **Deploying the notebook as-is would deploy the non-reproducibility this
project's paper indicts**, and would violate the competition's reproducibility requirement.

Cell 3 gates the real run behind `if os.getenv('KAGGLE_IS_COMPETITION_RERUN')`, so the
notebook is the *only* deployment artifact; a commit-mode run never exercises the agent.

## 2. The seed rule (NBT1 — DONE, measured)

The agent is a high-variance policy and the leaderboard samples it once. Measured on the
full 25 released games, over the **pre-registered fixed list `1..20`**:

```text
min 0.1367 (seed 6)    max 0.9859 (seed 15)
mean 0.4270            MEDIAN 0.4052
ordered: 0.1367/s6 0.1382/s19 0.1843/s10 0.2269/s3 0.2408/s11 0.2505/s13
         0.2672/s12 0.3390/s1 0.3982/s5 0.4042/s16 0.4063/s2 0.4239/s14
         0.4825/s20 0.5222/s8 0.5551/s17 0.5965/s18 0.5980/s4 0.6136/s9
         0.7694/s7 0.9859/s15
```

**Deployment rule: pin the seed whose measured score is the median of the pre-registered
list — `ARC3_AGENT_SEED=16`, measured 0.4042.** The rule is a *rank statistic*, not an
optimum: a median is not selected for its value. The maximum (**seed 15 = 0.9859**) is
**rejected**: selecting it is fitting the 25 games that constitute the test set, and
publishing it as the agent's capability would be a false number.

The full distribution ships in the output documentation and the paper, so any reader can
re-run any seed and check both numbers.

Baseline for comparison: the deployed v2 scores **0.28** on the leaderboard; v3 with the
code's own default seed (`zlib.crc32(game_id)`) measures **0.2017**, i.e. a regression.

## 4. Invariants the builder must satisfy

1. **`python3 scripts/build_arc3_notebook.py --check` exits 0** on the committed notebook.
   This is the anti-drift mechanism: drift becomes structurally impossible, not a matter
   of discipline.
2. **The agent cell body is byte-identical to `src/arc3_spatial_memory_agent.py`**
   (modulo the `%%writefile` first line). This is what is asserted, not "similar to".
3. **`--check` must fail when the notebook is edited by hand.** A drift detector that
   cannot detect drift is worse than none.
4. **The seed is declared, not implicit.** `ARC3_AGENT_SEED=16` is exported by the
   generated runner cell, and the rule and its justification appear in the notebook's
   markdown header so the artifact states its own provenance.
5. **The existing runner cells are preserved in behaviour.** Cell 1 (`pip`), cell 3
   (gateway wait, framework copy, agent drop-in, run) and cell 4 (commit-mode dummy
   submission) keep their semantics; only their provenance changes.

## 5. Non-goals

- No change to the agent's algorithm. The probe already measured the heuristic layer inert
  (`odd/tasks/arc3-strategy-probe.md`); this feature changes only how the artifact is built.
- No new measurement of the agent's capability. The distribution in §2 is the record.
- No external publishing. Push and submission are NBT6 and the owner's decision.
